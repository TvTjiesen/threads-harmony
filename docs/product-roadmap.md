# Threads 鸿蒙客户端：从体验候选到日用版

目标是 **Pura X View 优先**的非官方鸿蒙客户端：原生导航、阅读、无障碍和媒体体验由 ArkUI 与公开的 UIDesignKit 实现；真实账号能力只使用官方网页或取得许可的 Threads API。MatePad Edge 是多窗、键鼠及独立构建验收站，不挡 Windows 开发。项目当前交付的是可签装的**本机体验候选**，不是可登录的原生 Threads 替代品。

## 下一组五项，放进同一个候选

| 项目 | 实现步骤 | 关卡 |
| --- | --- | --- |
| 1. 可重复的设备回归 | 把手工探针中稳定部分整理成独立用例：草稿、两流读位、精确回复、搜索清除、资料保存、图集和播放器生命周期。仅用演示内容，从固定提交构建，回执包含系统/API、窗口、输入方式与失败步骤。 | 同一提交在手机模拟器可复跑；MatePad 回执可异步补充；无账号日志、签名或私人内容。 |
| 2. Pura X View 折叠与硬件输入 | 连接自有真机，记录各形态的应用可用宽度和系统安全区；测首页/详情/草稿/媒体内折展和系统侧滑。MatePad 对照连续缩放、窄窗分屏、Tab/Shift+Tab、方向键与键盘返回。只修复能复现的断点和焦点问题。 | 折展前后不丢帖子、回复目标、草稿、图序或播放意图；外屏和极大字号没有被遮住的必要按钮。无设备则标未测，不替代验收。 |
| 3. 原生审美与无障碍 | 以 HarmonyX 的公开导航思路为参照，不复制私有源码和素材。建立同屏对照：冷启动、首页、回复进入/返回、写帖键盘、照片、视频、设置；检查触达区、留白、对比、焦点顺序和语义。用公开原生控件统一转场；正常和减少动效分别录制；用真机检查系统读屏。 | 标准/特大字号与深浅色均可读可点，焦点可返原处；减少动效不影响操作结果。审美需要用户看实拍判断，不以编译证明。 |
| 4. 帧率、启动和内存 | 用官方 Profiler/系统跟踪采集实际首帧、FrameTimeline、主线程、峰值内存；固定设备、刷新率、构建、数据和采样方法。分别测冷启、快速滚动、四图翻页、多段媒体、后台恢复。先定位热点，再决定虚拟化、解码窗口、描述符与缓存上限。 | 保存同机前后样本和中位数/P95；报告掉帧、内存和崩溃，不把 HDC 命令和 UI 树等待当首帧。 |
| 5. 网页和真实只读的验收准备 | 保持当前网络设置不变。用户恢复网络后，先在 Pura X View 同网对照系统浏览器与 ArkWeb 首屏、登录、前后台和外链；然后在受信开发机验证 Graph HTTPS。只有已获批时，才由用户在本机配置令牌，测公开关键词、公开用户名、分页和失败重试。 | 浏览器/ArkWeb/Graph 分别记证据。双方网络不可用则先完成其余四项，Meta 权限不足仍明确标注，不把离线样本当真实结果。 |

## 之后的里程碑与用户要求

1. **日用混合版。** 先验证官方网页所提供的推荐与关注、搜索、发布、回复、关注、私信/群聊和会话续用；网页允许且用户授权时才操作可清理内容。定位嵌入问题时使用相同设备和网络，保留系统浏览器入口。网页不支持或 ArkWeb 不兼容的功能明确标限，不尝试共享 Cookie，不把原生预览说成真实发布。
2. **有授权才原生化。** 将公开读取做成显式来源，与本机内容和网页登录分离；按 Meta 最新批准范围和实证决定搜索、创作者公开资料及所有者功能。发布、回复管理等先验证 scope 与用户确认流程，再做原生写操作、重试、去重及结果校验。没有受支持接口的账号首页/关注流、私信、推送等继续官方入口，或不做；不抓会话、不用私有接口复刻。
3. **系统能力分级。** 现有 HDS 导航、系统相册/文件、分享、深浅色、字号及减动效从功能验收到真实设备。对用户点名的沉浸光感、智感卧姿，核对目标机系统版本、公开 API/SysCap、设备设置与最小演示；有公开能力且真机通过才写支持，否则尊重系统默认表现并清楚标注。普通模糊不是沉浸光感，屏幕方向不是卧姿识别。通知、桌面卡片、跨设备、后台与功耗先核查系统权限和可用数据源，再排期。
4. **数据、隐私与发布。** 明确本机存储、官方网页和官方接口的边界；完善资料和草稿清理、媒体引用及空间上限、必要时备份/恢复和迁移。建立干净安装、覆盖升级、签名差异、回滚和日志脱敏测试。内测只分发合适签名的包，列兼容系统机型和非官方声明；商店发布另评审平台规范、品牌素材和 Meta 条款，不提前承诺过审。
5. **Android 与跨设备放后。** 鸿蒙手机日用及多窗验收过关后，才单独验证 Android 原生 UI 与官方网页兜底，复用设计变量和接口契约，不复制 ArkTS 实现或迁移凭据。在此之前不因为跨端而延迟 Pura X View。

工作节奏：后续继续按一组五项并行、集成一份固定提交；子代理写入范围分开，Windows 主责核对差异、实编签装和回归。每组给 MatePad 可复制中文任务单，并区分已完成、还没测、等设备或授权这三种状态。MatePad 测试可暂缓，不会用旧回执替代当前候选。见[测试矩阵](../TEST-MATRIX.md)。
